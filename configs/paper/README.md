# Retired protocol-v1 paper configurations

The YAML files in this directory reproduce the exploratory protocol used by
the pre-revision manuscript. They are retained for provenance only. Their test
seed and evaluation protocol were exposed during method development, so their
outputs must not be reported as protocol-v2 independent final-test results.

New candidate protocols live in `configs/protocol_v2_candidates/`. Final
protocol-v2 configurations will be added only after the study lock is frozen.
